Setup Runbook — Onboarding a New User

Do all of this at their machine (or via remote desktop). Have this portal open on your own screen.

  1. On their PC — Node.js. Check node --version in cmd. If missing or below v18, install the LTS from nodejs.org and reboot.
  2. On their PC — Claude Desktop. Install from claude.ai/download if missing. Sign them in with their Claude Pro account. Tray-quit after confirming it runs.
  3. On their PC — Prospect PAT. Log them into Prospect365 in a browser. Settings → Integrations → API → Personal Access Tokens → create one named "Claude MCP" and copy it immediately (it's not shown again).
  4. On their PC — run the setup script. In PowerShell:
    \\192.168.1.155\sfm_data\prospect-mcp\scripts\setup-user.ps1
    Enter their user code and paste the PAT when prompted. If PowerShell blocks the script, first run Set-ExecutionPolicy -Scope CurrentUser RemoteSigned.
  5. On your PC — this portal. Click + Add User, enter their code, name, notes. Leave the PAT field blank (their machine has its own copy). Tick the permissions that match their role. Save Permissions.
  6. On their PC — restart Claude Desktop. Right-click the tray icon → Quit. Reopen from the Start menu. (Required once — later permission changes do NOT need another restart.)
  7. On their PC — verify. In a new Claude chat, ask "search quotes for Exeter University". Should return a list. Done.
Notes:
  • Permission changes take effect within ~5 seconds — no Claude restart needed once they're set up.
  • Their PC needs network access to \\192.168.1.155\sfm_data. No drive mapping required — the UNC path works directly.
  • Manual fallback if the script fails: click Config next to their name above and copy-paste into %APPDATA%\Claude\claude_desktop_config.json on their PC.
  • Full runbook with troubleshooting + removal steps: docs/ADMIN-SETUP-RUNBOOK.md in the repo.
